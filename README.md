# C-Quests: Учебные задачи на языке C

Этот проект включает серию практических заданий, которые я выполнил для улучшения навыков программирования на языке C. Задачи охватывают основы работы с форматированным выводом, арифметическими операциями, обработкой ошибок и математическими функциями.

## Основные темы
- Форматированный вывод текста.
- Обработка ввода и ошибок.
- Арифметические операции и работа с плавающей точкой.
- Применение математических функций.

Проект был выполнен с использованием стандартов C11, компилятора GCC, а также с соблюдением стиля кодирования Google C++ Style Guide.
